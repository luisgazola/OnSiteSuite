# Security policy — OnSiteSuite 2.0.0

Please report vulnerabilities privately to the project owner through the repository's security advisory channel, if configured. Do not post sensitive host logs, client data, or serial numbers in a public issue.

The application is offline-first and collects locally available hardware/software metadata. Review generated reports before sharing. Linux report directories are private by default; Windows permissions depend on destination ACLs.

See `docs/SECURITY.md` for consent, network, printing and privileged-operation rules.
